# SelecT

一款安卓翻译工具，核心是选中文字后快速得到中文译文，并且不遮挡原文。

## 当前功能
- 手动输入或粘贴文字翻译，默认英译中
- 系统选中文字后，直接使用“翻译”菜单入口，无需无障碍授权
- 开启无障碍服务后，选中文字会自动翻译，并在选区附近直接显示译文，无需点击
- 支持从 GitHub、浏览器等应用“分享文本到 SelecT”，打开后自动翻译
- 译文浮层会一直保留，直到手动点右上角关闭或切换到其他应用
- 提供快捷设置磁贴，可添加到下拉控制中心，一键打开翻译或无障碍设置
- 本地词典优先，速度快，适合离线场景
- 常见词直接命中本地词典，其他文本自动走在线翻译，并带双接口兜底
- 历史记录和收藏内容
- 离线模式开关
- 底部导航分为翻译页和权限设置页
- 悬浮窗权限开启后即可使用 App 内翻译，不强制要求无障碍服务
- 无障碍服务属于可选项，只用于自动捕获选中文字

## 权限说明
- 无障碍服务：用于在其他应用里读取选中的文字，属于可选项
- 悬浮窗权限：仅用于 App 内的悬浮球等增强功能，全局译文浮层不再依赖它

## 框选即译
- 无障碍服务会监听文字选择事件，优先从节点读取选中文本
- 浏览器、WebView 等拿不到选区文本时，自动执行复制，再由一个透明页面读取剪贴板后立刻关闭
- 整个过程不需要点击“复制”或“翻译”，只会在选区旁显示译文浮层
- 权限页带有“最近事件”诊断，框选无反应时可以回来查看卡在哪一步

## 构建
```bash
gradlew.bat assembleDebug
```

## 测试
```bash
gradlew.bat testDebugUnitTest
```

## 安装
生成后安装 `app/build/outputs/apk/debug/app-debug.apk` 到手机即可。

## 目录
- `app/` 应用代码
- `docs/` 设计与说明
- `gradle/` 构建配置
- `scripts/` 构建辅助脚本
